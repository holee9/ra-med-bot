### 개선할 점

1. **gh CLI PATH 문제**
   - bash 세션에서 `gh` 직접 호출 불가
   - 절대 경로 사용 필요: `/c/Program Files/GitHub CLI/gh.exe`
   - 향후 PATH 등록 필요

2. **Wiki 초기화 자동화 부족**
   - 첫 페이지 생성이 수동
   - 스크립트로 자동화 가능할지 검토
