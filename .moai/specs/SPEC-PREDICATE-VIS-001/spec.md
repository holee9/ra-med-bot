# SPEC-PREDICATE-VIS-001: Predicate 비교 분석 시각화 개선

## 목표
Predicate 비교 분석 시각화를 입결전 상태까지 완성하여 기술 투자자 및 마케팅용 데모를 지원

## 배경
현재 테이블 기반 비교 UI는 기능적이지만 시각적 직관성이 부족하여 입결전 단계에서의 가치 전달이 어려움

## 개선 요구사항

### REQ-VIS-001: 인터랙티브 시각화
- **현재**: 정적 테이블 기반 비교
- **개선**: 
  - Recharts 기반 인터랙티브 차트 구현
  - 호버/클릭 시 상세 정보 표시
  - 필수 문서 vs 선택 문서 색상 구분

### REQ-VIS-002: Before-After 비교 모드
- **현재**: 단일 모드 비교만 지원
- **개선**:
  - Before-After 토글 기능
  - 변경 사항 하이라이팅
  - 진행 과정 시각화

### REQ-VIS-003: 필수 문서 vs 선택 문서 시각적 구분
- **현재**: 텍스트로만 구분
- **개선**:
  - 색상 코딩 (필수: 파란색, 선택: 회색)
  - 아이콘/심볼 추가
  - 진행 상태 표시

### REQ-VIS-004: 입결전용 마케팅/UI
- **현재**: 기능 중심 UI
- **개선**:
  - 투자자/고객용 데모 모드
  - 애니메이션 효과
  - 반응형 디자인 완성

## 구현 계획

### Phase 1: 기존 코드 분석 및 설계
- ComparisonTable 컴포넌트 분석
- PredicateComparison 타입 이해
- 시각화 라이브러리 선정 (Recharts vs D3)

### Phase 2: 시각화 컴포넌트 개발
- 인터랙티브 차트 컴포넌트
- Before-After 비교 모드
- 필수/선택 문서 시각적 구분

### Phase 3: UI/UX 개선
- 반응형 디자인
- 애니메이션 효과
- 데모 모드

### Phase 4: 테스트 및 배포
- E2E 테스트 작성
- 성능 최적화
- 프로덕션 배포
