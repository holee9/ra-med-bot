## 1. RA 팀 (3-4명) — 핵심 규제 전문가

### 1.1 RA Lead (1-2명)

#### 실제 업무 시나리오

**09:00-09:30: CER 문헌 검색 시작**
- **목표:** Cardiovascular stent 관련 최신 문헌 50개 이상 수집
- **기존 방식:** PubMed, Google Scholar 수동 검색 (40-80시간)
- **Regula 활용:** RAG 기반 Q&A + PubMed 자동 수집 (10-15시간)
- **수행 단계:**
  1. Regula 접속 및 CER 워크플로우 시작
  2. 검색 쿼리 입력: "cardiovascular stent clinical outcomes"
  3. PubMed 자동 수집 실행
  4. 수집된 문헌 확인 (50개 이상)

**09:30-10:00: SIGN 50 평가 기준 1차 필터링**
- **목표:** 수집된 문헌 50개 중 SIGN 50 평가 기준으로 1차 필터링
- **기존 방식:** 수동 평가 (5-10시간)
- **Regula 활용:** SIGN 50 자동 평가 (30분)
- **수행 단계:**
  1. Regula SIGN 50 평가 도구 실행
  2. 자동 필터링 결과 확인
  3. 1차 통과 문헌 선별 (예: 15개)

**10:00-11:00: 임상 Lead와 협의**
- **목표:** 1차 통과 문헌 15개에 대해 임상적 타당성 검토
- **기존 방식:** 이메일/전화 협의 (비효율)
- **Regula 활용:** 협업 기능 (실시간 코멘트 + 공유)
- **수행 단계:**
  1. Regula 협업 기능 호출
  2. Clinical Lead에게 검토 요청
  3. 실시간 피드백 수신

**11:00-13:00: Predicate device 비교 분석**
- **목표:** Predicate device 3개와 기술적 비교 분석
- **기존 방식:** 수동 비교 분석 (수 시간)
- **Regula 활용:** Predicate 비교 분석 자동화 (수십 분)
- **수행 단계:**
  1. Regula Predicate 비교 도구 실행
  2. 대상 device 3개 선택
  3. 자동 비교 분석 결과 확인

**14:00-16:00: PCCP 초안 작성**
- **목표:** PCCP (Principle Components and Characteristics) 초안 작성
- **기존 방식:** 수동 가이던스 참조 (4-5시간)
- **Regula 활용:** PCCP 4단계 위저드 (2-3시간)
- **수행 단계:**
  1. Regula PCCP 위저드 시작
  2. 4단계 구조화된 작성
  3. 자동 포맷팅 및 검증

**16:00-18:00: 팀 전체 리뷰 및 Expert Review Gate 승인**
- **목표:** 팀 전체 리뷰 회의 및 최종 승인
- **기존 방식:** 오프라인 회의 및 수동 승인 (비효율)
- **Regula 활용:** 협업 기능 + Expert Review Gate (자동 추적)
- **수행 단계:**
  1. Regula 팀 협업 기능 호출
  2. 리뷰 회의 진행
  3. Expert Review Gate 승인
  4. audit_logs 자동 기록

#### Regula 활용 포인트

| 구간 | 기존 방식 | Regula 활용 | 시간 단축 |
|---|---|---|---|
| CER 문헌 검색 | 40-80시간 | 10-15시간 | 75-85% |
| SIGN 50 평가 | 5-10시간 | 30분 | 90% |
| Predicate 비교 분석 | 수 시간 | 수십 분 | 85% |
| PCCP 작성 | 4-5시간 | 2-3시간 | 50% |

#### Go/No-Go 기준

**Go:**
- FDA 510(k) 제출 경험 5년 이상
- EU MDR Class IIb/III 제출 경험 2건 이상
- FDA/EU MDR/MFDS/NMPA/PMDA 규제 지식
- 영어 문서 작성 능력

**No-Go:**
